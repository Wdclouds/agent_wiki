# 02-1 认识 API Key 与计费方式：Token 消耗与成本换算

使用普通的网页版大模型（如网页版 Kimi 或 ChatGPT），你是在别人的网站界面里打字。
但当你使用任何独立的 Agent 工具（如桌面助手、终端工具、代码插件）时，软件通常会弹出一个设置框，要求你填写两项内容：**`API Key`** 和 **`Base URL`**。

很多新生一看到这里就以为必须绑定境外信用卡、或者担心会产生高额扣费。本篇为你彻底拆解其背后的计费逻辑与换算公式。

---

## 1. 什么是 API Key 与 Base URL？

你可以把模型厂商（如 DeepSeek、阿里云、OpenAI）想象成一个**“云端中央计算厨房”**：

* **API Key（接口密钥）**：
  * **通俗比喻**：相当于你在食堂开办的**“专属饭卡卡密”**（通常形如 `sk-xxxxxxxxxxxx`）。
  * 任何 Agent 工具在替你调用模型算力时，都会向服务器出示这个卡密，服务器验证通过后，扣除你卡里的余额，并把计算结果返回给工具。
* **Base URL（接口请求地址）**：
  * **通俗比喻**：相当于这个食堂的**“取餐窗口网络地址”**。
  * 官方默认地址通常类似 `https://api.deepseek.com/v1` 或 `https://dashscope.aliyuncs.com/compatible-mode/v1`。如果你使用的是国内聚合平台，填入对应的 Base URL 即可无缝切换直连线路。

---

## 2. 什么是 Token？它是怎么计费的？

模型厂商不是按“按小时”或“按提问次数”收费，而是按实际处理的**信息碎片数量——Token（标记）**来计量。

### Token 与汉字/英文的换算直觉
* **英文**：1 个 Token 大约对应 0.75 个英文单词（约 4 个英文字符）。
* **中文**：主流针对中文优化过的模型（如 DeepSeek、通义千问 Qwen），**1 个汉字通常对应 1 ~ 1.5 个 Token**；对于一些老牌海外模型，由于中文分词表较小，一个汉字可能会被拆成 2 ~ 3 个 Token。

### 为什么输入（Input）和输出（Output）价格不一样？
查看价格表时，你会发现所有模型都是**“输入便宜、输出贵”**（输出单价通常是输入的 2 到 4 倍）：
* **输入 Token（Prompt Tokens）**：你发送给模型的提示词、背景资料和上传的文档。模型处理输入时可以并行批量预加载（Prefill），计算效率高，因此收费低；
* **输出 Token（Completion Tokens）**：模型自己吐出来的每一个字。大模型是“逐字自回归生成”的，生成每个字都需要重新跑一遍庞大的神经网络矩阵，耗费的算力高出数倍，因此收费较贵。
* **思考链 Token（Reasoning Tokens，如 DeepSeek R1 / o1）**：模型在给出答案前输出的“思考过程（Thinking 过程）”，**全部按照输出 Token 计费**。
