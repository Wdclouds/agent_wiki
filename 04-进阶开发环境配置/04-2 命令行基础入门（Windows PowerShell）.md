# 04-2 命令行基础入门（Windows PowerShell）

很多大一新生看到黑漆漆的命令行窗口（CMD、PowerShell、终端）就心生恐惧，生怕敲错一个字母把电脑搞报废。

本篇专门为你做“心理脱敏”与实操避坑，解决玩转 Agent 时在黑框框里踩得最惨的几个高频痛点。

---

## 1. 导读与心理脱敏：什么时候你才用得上终端？

> 💡 **给新生的免责声明**：  
> 如果你平时只使用网页版（Kimi、豆包、ChatGPT 网页版）或桌面客户端，**你完全可以跳过本篇**！  
> 只有当你遇到以下 4 种具体场景时，才必须打开终端：
> 1. **在 GitHub 或 B站抄作业**：想把别人写好的开源 AI 脚本（如自动抓取知网论文的 Agent）一键跑起来；
> 2. **使用专业的代码编程特工**：如 Claude Code、Aider 等，它们原生只活在终端里；
> 3. **为开源软件配置环境**：工具没有漂亮的设置界面，必须在终端注入 API Key 和代理端口；
> 4. **断网运行本地私有模型**：使用 Ollama 在自己笔记本上跑离线开源模型。

### 终端的基本直觉
* 把终端想象成一个**“没有鼠标界面的文件管理器”**：
* 每一行最前面的路径提示（例如 `PS C:\Users\YourName\Desktop>`），代表你当前正**“站”**在哪个文件夹里；
* 你输入的每一行命令，都是针对这个文件夹里的东西生效的。
* **工具推荐**：Windows 10/11 用户强烈推荐在应用商店安装并使用微软官方的 **Windows Terminal（Windows 终端）**，支持标签页多开与平滑的字体渲染，体验远好于老旧的蓝底白字窗口。

## 2. 新生三大“偷懒技巧”（告别手动敲长路径）

绝大多数新生敲命令翻车，都是因为手敲长单词拼错。掌握以下三个技巧，能省去 90% 的繁琐打字：

1. **Tab 键自动补全（核心神技）**：
   * 想进入某个叫 `my_python_project` 的文件夹，只需输入 `cd my` 然后按键盘 **`Tab`** 键，系统会自动帮你补全完整文件夹名！敲命令也是同理。
2. **把文件或文件夹“直接拖进黑框框”**：
   * 需要输入某个文件的完整路径时，千万不要手敲 `C:\Users\...`；
   * 直接从 Windows 资源管理器里选中该文件，**用鼠标按住拖拽进终端窗口**，系统会自动生成带双引号的完美绝对路径。
3. **资源管理器地址栏直达终端**：
   * 在电脑里打开目标文件夹，点击窗口顶部的**地址栏**，直接输入 `powershell` 然后按回车；
   * 打开的终端窗口默认直接定位在该文件夹下，省去手动输入 `cd` 翻山越岭。

## 3. 复制粘贴与“意外刹车”的巨坑

这是导致新生 Agent 任务无故阵亡的最高频事故点：

* ⚠️ **`Ctrl + C` 是紧急刹车，不是复制！**
  * 在日常 Windows 软件里，`Ctrl + C` 是复制；但在所有终端里，**`Ctrl + C` 的含义是“强制中断并杀死当前正在运行的程序”**！
  * 很多新生看到 Agent 正在打印长篇分析，习惯性按 `Ctrl + C` 想要复制，结果直接把正在思考的模型连接掐断了。
* ✅ **正确的复制与粘贴姿势**：
  * **复制**：在现代 Windows Terminal 中，用鼠标**划选文字，松开鼠标或按一下回车**，文字就已经自动复制到剪贴板了；
  * **粘贴**：在终端黑色区域**单击鼠标右键**，或者按快捷键 **`Ctrl + Shift + V`**。
* **上下箭头（`↑` / `↓`）**：
  * 按键盘的向上箭头 `↑`，可以快速调出你刚才敲过的历史命令，改个错别字直接按回车重跑，不需要重新输入整行。

## 4. 破除权限拦截：Windows 经典的“禁止运行脚本”

大一新生在运行虚拟环境激活脚本（`activate`）或各类第三方自动化工具（`.ps1` 脚本）时，PowerShell 必然会以极高概率爆出一大屏幕刺眼的红字：
> `无法加载文件 xxx.ps1，因为在此系统上禁止运行脚本。有关详细信息，请参阅 about_Execution_Policies...`

### 一键解除限制方法
这是 Windows 默认过于严格的安全执行策略所致。解决办法极其简单，直接在 PowerShell 中复制粘贴以下命令回车：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
回车后系统询问是否更改，输入字母 `Y` 再次回车。此后本台电脑上的所有脚本均可正常执行，且只针对当前登录用户生效，既方便又安全。

## 5. 变量配置：Agent 专用的“临时环境变量”

运行各类开源 Agent 时，官方文档常常要求“设置 API Key”。在 Windows PowerShell 中的标准语法如下：

* **注入 API Key**：
  ```powershell
  $env:DEEPSEEK_API_KEY="sk-xxxxxxxxxxxxxxxxxxxx"
  ```
* **注入代理网络**：
  ```powershell
  $env:HTTP_PROXY="http://127.0.0.1:7890"
  $env:HTTPS_PROXY="http://127.0.0.1:7890"
  ```
* **检查是否设置成功**：
  直接输入 `$env:DEEPSEEK_API_KEY` 然后回车，若控制台打印出了你的 Key 内容，说明注入成功。
* **安全特性**：
  这几个命令是**进程级临时生效**的。只要关掉这个黑框窗口，该变量立刻从内存中销毁，不会永久写入 Windows 系统注册表，安全防盗。

## 6. 红字报错自救常识：看懂最后 1~2 行

在终端里敲命令，遇到红色报错信息是家常便饭，请记住第一原则：**绝大多数红字只是参数填错或缺依赖，电脑绝对不会损坏。**

遇到一屏幕几十行红字，**不要从头看，直接看倒数 1 到 2 行**：
1. **`不是内部或外部命令，也不是可运行的程序`**（或 `CommandNotFoundException`）：
   * **含义**：电脑里没有安装这个软件，或者安装时没有勾选“Add to PATH（添加到系统环境变量）”。比如提示 `python 不是内部命令`，说明 Python 还没装好。
2. **`Permission denied` / `拒绝访问`**：
   * **含义**：权限不够。关闭当前窗口，在开始菜单里找到 PowerShell，鼠标右键选择**“以管理员身份运行”**。
3. **`No such file or directory` / `找不到路径`**：
   * **含义**：你敲的文件名拼错了，或者你当前没有站对文件夹。在终端里敲一下 `ls` 回车，看看当前目录下到底有没有这个文件。
