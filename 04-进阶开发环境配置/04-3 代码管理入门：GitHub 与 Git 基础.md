# 04-3 代码管理入门：GitHub 与 Git 基础

在 AI 与 Agent 的时代，绝大多数最先进的工具、论文复现代码和开源提示词库，全部第一时间发布在 **GitHub** 上。

掌握基础的 Git 知识，能让你在高校科研与大创竞赛中，从“到处求安装包”进化到“直接从全球技术源头获取一手工具”。

---

## 1. 搞清概念：Git 与 GitHub 不是一回事

很多纯新手容易把这两个词搞混：
* **Git（版本控制工具）**：安装在你电脑本地的一个小型软件。它的作用像游戏里的“存档点”，能够记录你代码和文档的历史版本，允许随时回滚；
* **GitHub（全球最大的开源代码平台）**：一个网站（[github.com](https://github.com/github.com)）。全世界的程序员和科研人员把他们用 Git 管理的代码存放在这个网站上，供所有人免费下载、协同修改与交流。

---

## 2. 跑通开源项目：新生必会的 3 个核心命令

作为纯使用者，你根本不需要去背几十个复杂的 Git 分支合并参数。要把一个开源 Agent 项目跑起来，你只需要掌握以下 3 条命令：

### ① 一键完整下载代码仓库：`git clone`
当你看到某个优秀的开源 Agent（例如项目地址为 `https://github.com/username/project-name`），在终端中敲入：
```bash
git clone https://github.com/username/project-name.git
```
Git 会自动在你的当前文件夹下新建一个对应的文件夹，并将该项目所有的源文件、说明文档、依赖清单完整下载到本地。

### ② 同步作者的最新修复：`git pull`
开源项目更新极快，作者今天修复了一个 Bug：
进入该项目文件夹后，只需敲入：
```bash
git pull
```
Git 会自动比对差异，只把作者最新更新的那几行代码拉取下来覆盖本地，不需要你重新下载整个压缩包。

### ③ 检查本地文件变动状态：`git status`
想看看自己有没有不小心改动了作者的文件，敲入 `git status` 即可一目了然。

## 3. 国内网络痛点突破：GitHub 下载慢或连不上怎么办？

国内校园网经常遇到 `git clone` 速度只有几 KB/s，或者直接报 `Failed to connect to github.com port 443: Timed out`。

以下是两种最实用的解决路径：

### 方案 A：让 Git 走本地代理端口（最彻底）
如果你本地开着代理客户端（假设本地端口为 `7890`），在 PowerShell 中敲入以下两行，为 Git 配置全局代理：
```powershell
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
```
* **如何取消**（如果之后不用了）：
  ```powershell
  git config --global --unset http.proxy
  git config --global --unset https.proxy
  ```

### 方案 B：小白退路：直接在网页端点击“Download ZIP”
如果完全不想配置 Git 命令行：
1. 用浏览器打开该开源项目的 GitHub 主页；
2. 找到绿色的 **`<> Code`** 按钮，点击下拉菜单；
3. 点击底部的 **`Download ZIP`**，直接把整个项目打包下载为普通压缩包，解压后即可直接使用。

## 4. GitHub 网页端找神器的两大秘籍

1. **认准 Releases 标签（找免编译成品）**：
   * 很多开源 Agent 项目为了照顾非程序员，作者会提前打包好免安装的 Windows 可执行文件（`.exe` 安装包）。
   * 打开项目主页，**看网页右侧栏的“Releases”**，点击进去通常能直接找到打包好的成品文件下载，无需自己在终端里跑编译！
2. **善用 Issues 搜索报错**：
   * 运行项目如果遇到报错，打开该项目的 **`Issues`** 页面，在搜索框中粘贴你的报错英文关键词。
   * 90% 的情况下，都有其他网友在两周前遇到过一模一样的错误，并且作者或热心人已经在评论区贴出了标准解法。
