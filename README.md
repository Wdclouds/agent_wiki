# 大学新生 AI Agent 实战指南（全学科通识版）

> 欢迎来到面向全校各专业新生的 AI Agent 知识库。  
> 本指南旨在帮助你从零建立对“人工智能智能体（AI Agent）”的正确认知，掌握用 AI 替你执行繁琐学业任务的方法，并安全避开费用扣划与环境配置的各类深坑。

---

## 🧭 全学科导读导航：你应该怎么读？

不同的专业背景和使用需求，阅读路径截然不同：

* **文史哲、社科、法学、医学与经管类新生**：
  * **必读路径**：`00-认知篇` → `01-核心机制与操作技巧` → `02-模型算力与费用指南` → `03-主流工具全景/01-桌面与办公协同类`。
  * **建议**：直接使用豆包工作模式、Workbuddy 或 Marvis，无需接触代码即可搞定长篇研报、文献精读、数据清洗与多语言对译。
* **理工科、计算机、软件工程与大创科研学生**：
  * **通关路径**：建议通读全部章节，重点攻克 `03-主流工具全景/02-代码与开发类`、`03-开源与自主执行框架` 以及 `04-进阶开发环境配置`。
  * **建议**：打通终端代理与 PowerShell 执行策略，掌握 Claude Code、Aider 等原生代码特工的本地沙盒排错能力。

## 🛡️ 新手安全三大底线

1. **预充值与限额原则**：使用 API Key 永远采用预付费充值（充 5~10 元即可），严禁盲目绑定无上限透支信用卡。
2. **凭据安全绝对保密**：严禁将含有 API Key（`sk-xxx`）的代码上传至公开 GitHub 仓库或发送在班级群中。
3. **保持批判与学术严谨**：Agent 是辅助思考和执行的数字工具，其生成结果尤其是引用文献必须经过人工核验，严禁无脑代写提交课程作业。
