# 01-2 工具与技能 (Tool & Skill)：智能体如何调用外部功能

大语言模型（LLM）本身只是一个“文字预测系统”。它既没有安装在电脑上的双手，也没有直接访问互联网的物理网卡。

那么，Agent 究竟是通过什么黑科技把你的本地文件读出来、把网页抓下来、把代码跑起来的？
答案就是：**函数调用（Function Calling）与工具体系（Tools & Skills）**。

---

## 1. 核心底层逻辑：函数调用 (Function Calling)

很多初学者误以为大模型自己在系统后台敲键盘，其实整个过程是**“模型发令，框架跑腿”**：

```text
  [人类用户] 下达任务："帮我看下当前目录下有哪些文件"
      │
      ▼
  [大模型 LLM] 不直接回答文本，而是输出结构化的调用指令（JSON）：
               {
                 "tool": "list_files",
                 "parameters": { "path": "./" }
               }
      │
      ▼
  [宿主框架 / Agent 程序] 收到指令，真正在操作系统中执行操作，获取到实际结果：
               ["chapter1.md", "data.csv", "notes.txt"]
      │
      ▼
  [回传给大模型] 框架把真实结果喂给模型："这是文件夹里的实际文件列表"
      │
      ▼
  [大模型综合汇报] 大模型阅读真实结果后回答用户："当前目录下包含 chapter1.md 等 3 个文件。"
```

这就是 Agent 能够触碰物理世界的全部秘密：
1. **开发者提前注册可用工具**：告诉模型“你今天可以使用计算器、搜索引擎和文件读取器，它们的输入格式分别是什么”；
2. **模型根据你的任务决定是否调用**；
3. **外部程序代为执行，并将真实数据送回大脑**。

---

## 2. 工具（Tool） vs 技能（Skill）：有什么区别？

在现代 Agent 体系中，大家经常听到 **Tool** 和 **Skill** 两个词，它们代表了两个不同层级的能力抽象：

| 维度 | 原子工具 (Tool) | 复合技能 (Skill) |
| :--- | :--- | :--- |
| **层级定位** | 最底层的单次原始操作 | 封装了专家经验与标准作业程序 (SOP) 的能力包 |
| **现实比喻** | 螺丝刀、锤子、扳手 | 拥有 5 年修车经验的技工手册与作业规程 |
| **操作例子** | `read_file`（读文件）、`bash`（敲命令）、`http_get`（发网络请求） | `latex-thesis-compile`（LaTeX 论文排版与编译） |
| **优缺点** | 灵活但细碎，如果完全让模型从零摸索，极易出错或遗漏步骤 | 规范、严谨、开箱即用，内置完整的自我检查和容错机制 |

### 典型实例：LaTeX 期末论文排版
* **如果只给 Agent 原子工具 (Tool)**：
  * 模型调用 `bash` 敲了一句 `pdflatex main.tex`；
  * 如果中间引用了参考文献（BibTeX），它可能忘了运行 `bibtex` 编译第二遍，或者遇到字库缺失时在终端死等，导致最终生成的 PDF 满篇问号。
* **如果挂载了成套技能 (Skill)**：
  * 技能包内部已经定义好标准规程：“① 检查本地 TeXLive 环境及字体包 → ② 执行初次编译 → ③ 自动解析并执行 `bibtex` 提取引注 → ④ 再次编译生成完整交叉引用 → ⑤ 检查日志中的 Overfull 溢出警告并修复”。
  * Agent 会像专业学者一样一丝不苟地跑完整个闭环。

## 3. 大学新生必知的常见工具分类

了解系统中有哪些工具，能帮你快速判断一个 Agent 是否适合你的当前任务：

1. **信息获取类工具**：
   * `web_search`（网络搜索引擎）：抓取实时最新资讯；
   * `web_extract`（网页正文解析）：把长网页转为无广告的纯文本或 Markdown；
   * `pdf_parser`（PDF 解析器）：提取学术论文文字与表格。
2. **本地环境与计算类工具**：
   * `file_io`（文件读写）：保存报告、生成 CSV、重命名文件；
   * `python_interpreter`（代码解释器）：现场计算数据、绘制统计图表、验证数学逻辑；
   * `terminal / bash`（系统终端）：运行编译命令、启动本地测试服务。
3. **日常办公与服务集成类工具**：
   * 飞书/钉钉文档与多维表格 API；
   * 邮件收发客户端；
   * 微信/QQ 消息机器人。

## 4. 新手避坑要点：巧妇难为无米之炊

* **看清工具边界**：
  如果一个 Agent 软件没有配置“联网检索工具”，就算你给它的提示词写得再天花乱坠，它也无法查到今天的新闻；同理，没有“本地文件读取权限”的云端助手，是无论如何也打不开你电脑桌面上的 Word 文档的。
* **明确工具调用的代价**：
  每次调用外部工具获取长篇网页或大文件，都会消耗大量的文字长度（Token）。学会精准限定读取范围（如“只读前两页”、“只抓取摘要”），是进阶省钱和提速的关键。
