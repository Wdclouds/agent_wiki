# 00-2 全学科新生使用场景（文史哲、理工、医学、经管）

在大学校园里，不同专业新生的日常学业痛点千差万别。Agent 不是计算机专业专属的“玩具”，只要你掌握了它的能力边界，各学科都能用它解决极为繁琐的重复性工作。

以下结合各学院真实课程与任务场景，梳理出最具性价比的落地用法。

---

## 1. 文史哲与外语类（人文社科）

对于中文、历史、哲学、外语、新闻传播等专业，核心学业负担在于**“海量文献阅读、史料考证、长篇论述与多语言处理”**。

* **场景 A：学术争鸣与学术史梳理（文献综述助手）**
  * **痛点**：老师要求写一篇读书报告或期末课程论文，最怕前言的“国内外研究现状”。面对十几篇核心期刊，不知道各路学者到底在争论什么。
  * **Agent 用法**：将 5~10 篇 PDF 论文投喂给支持长文档和代码执行的 Agent，下达指令：“提炼学者 A、学者 B 和学者 C 关于该历史事件性质的核心分歧，以‘核心论点、论据来源、主要争议’三列输出对比表格”。
* **场景 B：学术翻译与语料对齐**
  * **痛点**：普通机翻往往生硬晦涩，专业术语前后不一致。
  * **Agent 用法**：配置学术翻译提示词，让 Agent 先通读整章构建专有名词术语表，再逐段对译，并附带译注说明“为何此处选用此词”。

## 2. 理工科与计算机类（数理化生、工科）

对于数学、物理、化学、生物、机械、计算机等专业，日常核心痛点是**“繁重的数理推导、实验数据处理与代码调试”**。

* **场景 A：大学物理/化学实验数据批量拟合与出图**
  * **痛点**：做完大物实验，手头有几十组电压、电流或光强数据，用 Origin 或 Excel 手动计算不确定度和拟合曲线极其耗时且易算错。
  * **Agent 用法**：把实验测得的原始 txt/csv 数据直接丢给具备 Python 运行环境的 Agent，要求：“计算均值与 A 类/B 类不确定度，用 Matplotlib 绘制散点图并进行最小二乘法线性拟合，输出拟合直线方程 $R^2$ 值并保存高清图像”。
* **场景 B：高数与线代：不是直接要答案，而是分步诊断思维漏洞**
  * **痛点**：看课后习题参考答案只有一句“显然可得”，完全看不懂中间的变换逻辑。
  * **Agent 用法**：拍照上传题目草稿，指令：“指出我在第 3 步到第 4 步展开时的逻辑漏洞，给出洛必达法则在此题失效的原因，并推荐一种更简便的等价无穷小替换思路”。
* **场景 C：编程作业的本地沙盒诊断**
  * **痛点**：大一 C 语言、Python 入门时，编译报出一堆看不懂的段错误（Segmentation fault）或环境依赖缺失。
  * **Agent 用法**：使用代码特工类工具（如 Claude Code、Aider），Agent 本地读取项目文件夹，自行在沙盒中编译运行、打印报错调用栈、精准指出越界数组位置并修复。

## 3. 医学与生命科学类（基础、临床、药学、护理）

医学生学业压力极大，核心痛点是**“庞大的专业名词记忆体系、最新英文文献追踪与病例机制理解”**。

* **场景 A：PubMed 顶刊前沿追踪与 RCT 试验对比**
  * **痛点**：某种新型靶向药或疗法，短时间内发表了大量临床研究，难以在短时间内把握临床终点和疗效差异。
  * **Agent 用法**：让 Agent 检索近三年相关随机对照试验（RCT），自动提取：“样本量、给药方案、主要终点（PFS/OS）、主要不良反应（AE）发生率”，规整为临床试验比对清单。
* **场景 B：复杂病理与药理机制通路拆解**
  * **痛点**：教科书上的信号传导通路（如 RAS/MAPK 通路）错综复杂，纯靠死记容易混淆。
  * **Agent 用法**：让 Agent 将复杂的上下游调控网络以结构化 Markdown 或 Mermaid 流程图代码形式输出，清晰呈现激活物、受体、次级信使及最终生理效应。

## 4. 经管与法学类（金融、会计、工商管理、法律）

经管法学生需要大量接触**“行业数据、企业财报、宏观指标与法律裁判文书”**。

* **场景 A：上市公司财报分析与杜邦分解**
  * **痛点**：期末课程大作业需要分析某家上市公司的财务健康度，翻阅百页 PDF 年报抓取数字极易眼花。
  * **Agent 用法**：上传目标企业近三年年报 PDF，让 Agent 自动抓取资产负债表与利润表核心数据，计算净资产收益率（ROE）、资产周转率与权益乘数，并横向对比同行业中位线水平。
* **场景 B：法学案例裁判要旨归纳与法条检索**
  * **痛点**：分析复杂民商事案例时，需要从几十页判决书中提炼法院认定的关键事实与裁判尺度。
  * **Agent 用法**：输入判决书文本，指令：“提炼本案一审与二审的核心争议焦点，列出法官采信的证据链与适用的《民法典》具体条款，总结同类案件的裁判倾向”。

## 5. 校园综合日常（社团、学生会、学科竞赛）

不论什么学科，大学新生在课外活动中都会遇到类似的通用协作场景：

* **大创与“互联网+”竞赛申报书搭建**：
  * 不是让 Agent 凭空编造项目，而是把团队已有的技术/想法草稿喂给它，让它辅助完成“同类产品竞品调研分析表”、“商业模式 SWOT 矩阵梳理”和“项目实施甘特图排期”。
* **学生会/社团活动策划方案**：
  * 输入往年招新或晚会的基本数据、预算上限与活动场地，生成包含“场地布置方案、活动流程推进表、应急安全预案、宣传推文发布节点”的完整策划初稿。
