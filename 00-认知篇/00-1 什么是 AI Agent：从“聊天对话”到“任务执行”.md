# 00-1 什么是 AI Agent：从“聊天对话”到“任务执行”

如果你之前用过 ChatGPT、Kimi、豆包、DeepSeek 等大模型，你可能已经非常熟悉这样的互动：
在对话框里敲下一句话，模型给你吐出一大段回答。你觉得有用就复制走，觉得不满意就继续追问。

但今天学术界、产业界高频讨论的 **AI Agent（智能体）**，并不是“又一个换了皮的聊天框”。

---

## 1. 聊天对话 vs 任务执行：本质区别在哪里？

斯坦福大学与各大 AI 实验室将大语言模型（LLM）与智能体（Agent）的区别概括为一句话：**LLM 是概率预测下一个词的大脑，而 Agent 是装上了眼、耳、手、脚的数字执行人。**

| 比较维度 | 传统对话大模型 (LLM) | AI 智能体 (Agent) |
| :--- | :--- | :--- |
| **底层形态** | 被动应答（你问一句，它答一句） | 自主执行（你定目标，它自己分步跑） |
| **外部交互** | 只能处理你发给它的文字，触碰不到现实电脑 | 能读写本地硬盘、浏览网页、运行脚本、调用软件 API |
| **运行机制** | 单轮生成后即停止 | **ReAct 循环**（观察环境 → 思考下一步 → 调用工具 → 验证结果 → 修正重试） |
| **交付成果** | 一段建议文字（具体操作仍然要你自己做） | 直接交付最终结果（如：一份排好版的 Excel、一个生成的压缩包、一份发出的邮件） |

### 真实大学场景对比：写期末论文开题调研
* **普通聊天 LLM**：
  * 你问：“帮我出几篇关于‘洋务运动经济影响’的参考论文题目。”
  * 它回复：列出 5 个看起来很像那么回事的书目或题目（甚至有些文献是它自己捏造的“幻觉”）。你依然得自己去中国知网（CNKI）一篇篇手动搜索、下载 PDF、逐篇阅读摘抄。
* **AI Agent**：
  * 你下达目标：“检索近五年知网被引前 10 的洋务运动经济研究核心期刊论文，下载摘要，对比学者们对民用工业官督商办模式的核心争议点，整理成 Markdown 对比表格。”
  * Agent 会：
    1. 自主调用网络搜索工具或学术数据库接口；
    2. 抓取真实网页与文献摘要；
    3. 识别并剔除无关论文；
    4. 提炼观点并结构化整理；
    5. 直接输出带有真实信源引注的分析报告。

## 2. Agent 的经典技术构成（五大支柱）

一个完整的 Agent 并不是神秘黑盒，业界公认的 Agent 极简模型可以拆解为五个核心要素：

$$\text{AI Agent} = \text{大模型 (LLM)} + \text{目标规范 (Prompt)} + \text{工具箱 (Tools)} + \text{自主循环 (Loop)} + \text{宿主外壳 (Harness)}$$

1. **大脑 (LLM)**：负责意图理解、逻辑拆解和决策判断。
2. **目标规范 (Prompt)**：人类下达的任务指令、角色设定与操作禁区。
3. **工具箱 (Tools / Skills)**：赋予 Agent 操作外部世界的能力，如：文件读写、网页爬取、Python 解释器、终端命令等。
4. **自主循环 (Loop)**：目标未达成前，不断自我纠错、尝试新路径的自主推进机制。
5. **安全护栏 (Harness)**：对高危操作（如格式化硬盘、清空数据库、扣款支付）设置人类确认弹窗的防护机制。
