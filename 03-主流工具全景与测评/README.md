# 03-主流工具全景与测评：三大货架与全学科选型指南

> **导读**：市面上的 AI Agent 工具琳琅满目，从一键安装的国产桌面软件到需要敲命令行的硬核开源框架应有尽有。  
> 本模块将所有主流 Agent 划分为 **三大货架**，帮助各专业同学根据自身学业场景、技术基础与预算快速选型。

### 1. 01-桌面与办公协同类（全学科推荐）
* **定位**：面向全校各专业日常学业任务，无需编程基础，安装即用。
* **涵盖工具**：
  * **[豆包工作模式](./01-桌面与办公协同类/豆包工作模式（国产免配置入门）.md)**：国产免翻免配置，超长上下文精读研报与文献。
  * **[Workbuddy](./01-桌面与办公协同类/Workbuddy（桌面跨应用操作助手）.md)**：桌面跨应用操作助手，支持多窗口自动化与文件批量处理。
  * **[Marvis](./01-桌面与办公协同类/Marvis（个人工作流助手）.md)**：轻量级个人学术工作流与文献管理助手。

### 2. 02-代码与开发辅助类（工科/计科推荐）
* **定位**：面向计算机、软件工程、理工科实验数据分析及自动化开发。
* **涵盖工具**：
  * **[Claude Code](./02-代码与开发辅助类/Claude Code（终端开发 Agent）.md)**：Anthropic 官方终端智能体，架构级理解代码库与自动修复 Bug。
  * **[OpenAI Codex 体系](./02-代码与开发辅助类/OpenAI Codex（代码生成工具体系解读）.md)**：主流 IDE（VS Code / Zed）核心补全生态。

### 3. 03-开源与自主执行框架（进阶探索专区）
* **定位**：面向大创科研、学科竞赛、多智能体协作与系统级自动化。
* **涵盖框架**：
  * **[Hermes](./03-开源与自主执行框架/Hermes（多任务协同与调度框架）.md)**：具备持久记忆与自适应技能的多任务调度智能体。
  * **[DSH](./03-开源与自主执行框架/DSH.md)**：Agent 沙盒执行与环境隔离外壳。
  * **[OpenClaw](./03-开源与自主执行框架/OpenClaw.md)**：协议级交互与网络嗅探测试框架。
  * **[OpenCode](./03-开源与自主执行框架/OpenCode.md)**：社区轻量级开源 Agent 实验环境。
  * **[Pi](./03-开源与自主执行框架/Pi.md)**：极简轻量级 Agent 原型验证框架。

## 📊 飞书多维表格（Bitable）一键导入资产

为了方便大家在飞书知识库中以“多维表格看板”的形式直观筛选工具，本目录配套了预置的 CSV 数据集：

📁 **导入文件路径**：`03-主流工具全景与测评/全学科工具选型多维表格导入表.csv`

### 飞书导入步骤：
1. 打开飞书知识库或个人云文档，点击右上角 **新建 → 多维表格**；
2. 选择 **从本地导入数据 → CSV 文件**；
3. 上传 `全学科工具选型多维表格导入表.csv`；
4. 飞书会自动将“分类”、“适用学科”、“上手门槛”、“费用类型”识别为单选/多选标签；
5. 你可以一键切换为 **画廊视图 (Gallery)** 或 **看板视图 (Kanban)**，呈现精美的全校 AI 工具导购墙。
