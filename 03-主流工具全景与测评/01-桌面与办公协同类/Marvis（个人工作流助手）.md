# Marvis：个人工作流与多模型聚合助手

Marvis 是一款专注于个人提效、整合多种主流模型与预设工作流的综合型桌面 AI 助手工具。

---

## 1. 核心档案与指标卡

* **一句话定位**：多模型自由聚合、支持可视化工作流预设的个人桌面效率中枢。
* **适合谁用**：需要同时对比不同大模型产出质量的学生、经常需要批量进行长文润色/多语言互译的文科与经管类用户。
* **门槛指标**：
  * **网络要求**：国内模型免代理直连，海外模型需自配网络环境。
  * **费用门槛**：基础功能免费体验，支持用户自填个人 API Key 降低成本。
  * **操作难度**：★★☆☆☆（图形化桌面客户端，配置直观）。

---

## 2. 核心功能与亮点

1. **多模型自由聚合与同屏对比**：
   * 支持一键接入或切换调用国内主流大模型（DeepSeek、通义千问、GLM）以及海外顶尖模型。
   * 当你需要写一份重要的答辩自述或求职简历时，可以在同一个界面里让两个模型同时生成，横向比对各自的文笔与逻辑严密程度。
2. **模块化预设工作流（Workflow Presets）**：
   * 内置长篇学术综述提炼、学术论文润色、多语言对齐翻译、头脑风暴发散等多样化的一键式工作流卡片。
   * 用户无需每次重复手敲长串复杂的 Prompt，点击对应预设卡片即可自动加载标准作业规范。
3. **知识归档与碎片灵感沉淀**：
   * 对话生成的所有优质成果、代码片段或参考文献，支持一键保存为个人便签与分类知识库，方便期末复习或写报告时随时调用。

---

## 3. 新手上手指南

1. **下载与安装**：获取桌面客户端并完成常规安装；
2. **模型引擎配置**：
   * 初次使用可直接使用内置渠道；若想追求极致性价比，可进入设置页面，将自己在阿里云或硅基流动申请的 API Key 和 Base URL 填入；
3. **套用工作流体验**：
   * 选择“学术论文润色”工作流，粘贴一段自己写的期末小论文草稿；
   * 观察工具如何分步执行：“① 提取语法语病 → ② 替换高阶学术词汇 → ③ 输出修改前后对比表与修改说明”。

---

## 4. 优势与局限性对比

| 维度 | 优势 | 局限性与避坑提示 |
| :--- | :--- | :--- |
| **功能整合** | 免去在几十个网页标签页之间来回切换的烦恼，界面整洁统一 | 偏重于文本与文档层面的工作流协同，对系统深层硬件和终端命令无原生控制权 |
| **灵活性** | 既支持小白开箱即用，也支持进阶用户自定义 API Key 压低使用成本 | 涉及海外高阶模型时，仍需依赖稳定的本地网络环境 |
