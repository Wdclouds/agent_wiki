# 豆包工作模式：国产原生免配置办公协同

豆包是字节跳动推出的国内主流 AI 工具。随着智能体技术的普及，豆包网页端与桌面端逐步加入了“工作模式 / 深度思考与研究模式”，让纯小白用户在完全不需要配置任何梯子、终端和环境变量的前提下，体验 Agent 级的自主规划与信息处理能力。

---

## 1. 核心档案与指标卡

* **一句话定位**：开箱即用、国内直连、零门槛的国产原生办公协作 Agent。
* **适合谁用**：全校非计算机专业新生、文史哲/社科/经管学生、需要快速完成课题研报、文献综述和长文档提取的新手。
* **门槛指标**：
  * **网络要求**：国内免代理直连，速度极快。
  * **费用门槛**：微信或手机号直接登录，核心功能免费。
  * **操作难度**：★☆☆☆☆（纯网页/客户端交互，零代码门槛）。
* **官方入口**：[https://www.doubao.com](https://www.doubao.com)（或下载豆包电脑客户端）。

---

## 2. 核心功能与自带工具链

豆包在“工作模式”下并不是简单的单问单答，它在后台已经挂载了成套的 Agent 执行工具：

1. **自主意图规划与深度研究（Deep Research）**：
   * 面对复杂问题，它会自动将任务拆解为 3~5 个子搜索词，并发检索全网数十篇权威报告或网页，自主阅读过滤后，输出带有详细参考信源引注的长篇结构化报告。
2. **长篇文档多格式解析（PDF / Word / Excel）**：
   * 支持一键上传百页学术论文、行业报告或课程讲义，自动提取核心结论、识别表格数据，并支持多轮基于原文的精准问答。
3. **云端 Python 代码沙盒与数据可视化**：
   * 遇到复杂数学计算或统计图表绘制需求时，它可以在云端后台自动编写并运行 Python 脚本，直接把跑出来的计算数值和生成的折线图、柱状图渲染交付给用户，支持打包下载。

## 3. 新手 5 分钟上手实操

以大学高频场景“写一份新能源汽车发展趋势开题背景调研”为例：

1. 登录豆包网页端或客户端，在输入框模式中切换至 **“深度思考 / 工作模式”**；
2. 输入提示词：
   > *“请调研近两年我国新能源汽车在固态电池与快充技术领域的最新产业化落地进展，整理出代表车企、关键技术路线、量产时间表三个维度的对比表格，并总结当前面临的核心工程瓶颈，附带信源出处。”*
3. **观察 Agent 自主执行过程**：
   * 你会看到界面上动态展示它的思考日志：“正在规划检索方向...” -> “检索到 12 篇网页，正在阅读比对...” -> “剔除失效信息...” -> “正在生成结构化表格”；
4. **获取成果**：数分钟后直接得到一份排版规整、论据清晰的专业调研简报。
