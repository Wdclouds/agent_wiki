# 01-桌面与办公协同类 Agent 测评专区

本板块精选目前最适合**全校各专业新生（文史哲、理工、医学、经管）**开箱即用的桌面与云端办公协同类 Agent。

---

## 1. 为什么全学科新生首选这一类？

* **零代码与零配置**：全部提供图形化界面（GUI）或网页端，完全不需要打开黑框框终端，不需要安装 Python 或 Node.js 环境；
* **即时正反馈**：下载安装或扫码登录即可直接使用，支持微信、QQ 或手机号一键登录；
* **专注于日常高频痛点**：深度论文阅读、多格式文件转换、长网页总结、表格数据自动汇总等。

## 3. 本板块推荐使用建议

1. **纯新手第一天**：建议直接从【豆包工作模式】体验起，先感受“AI 自动拆解任务、全网搜集 10 篇网页并输出研报”的能力；
2. **进阶日常办公**：如果觉得在不同网页标签之间来回切换麻烦，可以在电脑上常驻【Workbuddy】，利用全局快捷键随时划词处理文献；
3. **多模型综合对比**：如果需要写重要立项报告或比赛申报书，可以用【Marvis】让不同模型同时给出思路对比。
