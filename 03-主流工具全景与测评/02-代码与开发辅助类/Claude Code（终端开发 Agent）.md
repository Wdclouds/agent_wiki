# Claude Code：原厂终端自主编程 Agent

Claude Code 是 Anthropic 官方推出的原厂终端命令行 Agent 工具，专为在开发者的本地代码仓库中自主执行中大型工程任务而设计。它是目前全球公认最强、工程化程度最高的终端原生代码特工之一。

---

## 1. 核心档案与指标卡

* **一句话定位**：运行在操作系统黑框框（终端）里的“高级全栈工程师”。
* **适合谁用**：工科与计算机专业学生、经常需要调试多文件代码大作业、厌倦了网页来回复制粘贴的开发者。
* **门槛指标**：
  * **网络要求**：必须能够连通 Anthropic 官方服务器（终端需配置代理端口）。
  * **环境依赖**：本地需预装 Node.js（推荐 v18 或更高版本）。
  * **费用门槛**：消耗官方 Anthropic API 余额（或绑定官方订阅）。
  * **操作难度**：★★★☆☆（需在终端敲命令启动，但交互全中文自然语言）。

## 2. 获取与安装配置（国内网络优化版）

Claude Code 通过 `npm` 全局包管理器安装：

### 第一步：配置国内加速镜像（避免安装卡死）
在 PowerShell 中运行：
```powershell
npm config set registry https://registry.npmmirror.com
```

### 第二步：全局安装 Claude Code
```powershell
npm install -g @anthropic-ai/claude-code
```

### 第三步：终端代理与启动配置
因为 Claude Code 运行在终端中，默认不走系统浏览器代理，启动前必须让当前终端走代理：
```powershell
$env:HTTP_PROXY="http://127.0.0.1:7890"
$env:HTTPS_PROXY="http://127.0.0.1:7890"
```
*(注意：请将 `7890` 替换为你本地网络客户端的实际监听端口)*

## 3. 核心能力与内置工具链

与普通的聊天模型不同，Claude Code 在终端启动后直接挂载了严密的代码工程工具：

1. **全局文件树检索（Glob & Grep）**：
   * 毫秒级遍历项目上百个源码文件，根据函数名、变量名快速定位故障文件，不需要人类指定路径。
2. **局部精准替换（String Patch）**：
   * 绝不盲目重写整个大文件，而是精确匹配代码上下文进行局部修改，极大降低破坏已有代码的风险。
3. **真实环境构建与测试（Bash Execution）**：
   * 自动在项目目录下执行 `gcc`、`python` 或 `pytest` 命令，直接读取控制台报错信息进行针对性修复。
4. **安全护栏机制（Human Confirmation）**：
   * 在执行高危文件删除（如 `rm`）、外部网络推送（如 `git push`）之前，会自动暂停并强制人类敲击回车确认。

## 4. 新手 5 分钟上手实操

1. 打开任意一个你正在写的课程大作业项目文件夹（如 Python 小游戏或 C 语言课设）；
2. 在该文件夹空白处右键选择“在终端中打开”，敲入启动命令：
   ```powershell
   claude
   ```
3. 首次启动会引导完成账号授权；进入后直接输入自然语言任务：
   > *“请阅读当前项目的所有源文件，找出 `calculate_grade` 函数在输入负数时可能导致的崩溃逻辑，修复它，并为该函数补充 3 个单元测试用例。”*
4. **观察执行**：Claude Code 会自动翻阅代码、精准打补丁修改、运行测试验证，最后输出简洁的修改总结报告。

## 5. 新手常见报错与排查

* **报错 `ConnectTimeout` / `Connection refused`**：
  * **原因**：当前终端窗口没有配置代理环境变量，导致直连超时。
  * **解法**：重新执行前文的 `$env:HTTP_PROXY` 命令。
* **报错 `Credit balance is too low`**：
  * **原因**：官方账户 API 余额不足。需登录 Anthropic 控制台充值或检查绑定状态。
