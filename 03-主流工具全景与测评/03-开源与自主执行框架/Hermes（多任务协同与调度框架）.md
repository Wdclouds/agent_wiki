# Hermes：多任务协同与调度工作空间

Hermes 是一款专注于多智能体协同流转、技能扩展与任务分发调度的开源自主 Agent 框架。它的设计灵感来源于古希腊神话中的信使赫尔墨斯，旨在作为多设备、多工具与多角色智能体之间的协作中枢。

---

## 1. 核心档案与指标卡

* **一句话定位**：支持子智能体并行派发、多工具挂载与跨平台网关联动的全能 Agent 调度框架。
* **适合谁用**：计算机与工科高年级学生、对智能体协同系统感兴趣的科研/大创团队、希望搭建自动化生产力助手的极客。
* **门槛指标**：
  * **环境依赖**：Python 3.11+、支持本地或云端 Linux / WSL / macOS 环境。
  * **费用门槛**：按调用的底层大模型 API 计费，支持接入各类 OpenAI 兼容接口（如 DeepSeek、Qwen 等）。
  * **操作难度**：★★★☆☆（需具备基础 Python 环境配置与终端命令常识）。

---

## 2. 核心架构与技术亮点

1. **子智能体并行派发（Subagent Delegation）**：
   * 面对复杂的长链条任务（如“同时调研 3 家不同公司的技术架构并出对比报告”），主控 Agent 不会亲自耗尽自身上下文，而是通过 `delegate_task` 启动独立的轻量沙盒子智能体并行工作，子任务完成后自动向主控汇总结果。
2. **规范化的技能插槽生态（Skill System）**：
   * 采用高度结构化的 `SKILL.md` 规范。开发者可以将特定垂直领域的标准作业程序（SOP，如“GitHub 自动发版”、“高数成绩加权计算”、“文档表格清洗”）封装为独立技能，随时热插拔挂载。
3. **严格的执行纪律与安全护栏（Safety Discipline）**：
   * 内置生命周期拦截钩子，针对持久化存储修改、破坏性命令（如删除文件）、网络外部推送等高危操作提供严密的预检与确认审计机制，防止 Agent 越界失控。
4. **多端网关与无缝集成（Gateway & Channels）**：
   * 既能以原生 CLI 终端运行，也支持打通 Telegram、Discord、微信等多端通信网关，实现随时随地远程唤醒与指令指派。

---

## 3. 典型大学科研与大创应用场景

* **多源情报与文献自动巡检（Watchdog）**：
  * 配置定时任务（Cronjob），每天早晨自动抓取特定领域（如具身智能、量子计算）的最新 ArXiv 论文或热点资讯，提炼结构化摘要推送到个人消息群。
* **协同编程与自动化回归测试**：
  * 主控负责下达功能需求，子 Agent A 负责编写业务逻辑，子 Agent B 负责编写边界单元测试并执行覆盖率检查，最后由审校 Agent 合并代码。
