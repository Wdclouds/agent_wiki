# OpenCode：开源透明的终端代码智能体

OpenCode 致力于让代码 Agent 的整个思考过程、文件操作和执行记录完全透明、可回溯，专为注重数据自主权和本地私有化部署的开发者打造。

---

## 1. 核心档案与指标卡

* **一句话定位**：开源、可自托管、运行透明且深度兼容本地私有模型的终端代码 Agent。
* **适合谁用**：涉密实验室课题组成员、对隐私有严格要求的开发者、希望探究代码 Agent 内部工作原理的学习者。
* **门槛指标**：
  * **环境依赖**：Node.js / Python 环境，支持跨平台终端。
  * **操作难度**：★★★☆☆。

---

## 2. 核心架构与功能亮点

1. **执行过程 100% 透明与本地化回溯**：
   * 区别于商业商业软件的黑盒运行，OpenCode 产生的每一次文件读取、每一行代码补丁（Diff）、每一次终端命令调用均保存在本地结构化日志中，支持随时回放与一键撤销。
2. **多模型自由热插拔（尤其对本地模型友好）**：
   * 既能接入云端顶尖推理模型（如 DeepSeek-R1、Claude、GPT-4o），也能通过标准 OpenAI 兼容接口，无缝连入本地运行的 **Ollama** 或 **vLLM**（如本地部署的 `Qwen2.5-Coder-7B/14B` 或 `DeepSeek-Coder`），真正实现断网无网络环境下的全本地自主代码生成。
3. **结构化 Diff 实时比对与交互审查**：
   * 在实际向本地文件写入修改前，在终端中以红绿色彩高亮直观呈现将要变动的代码行，用户可逐项按 `Y` 批准或按 `N` 否决，将控制权完全保留在人类手中。

---

## 3. 适用场景与实践价值

* **校内私有云与涉密项目开发**：在完全断开外网的局域网机房中，配合本地 GPU 工作站跑本地代码大模型辅助科研；
* **Agent 源码二次开发与教学**：代码结构清爽、无闭源混淆，是高校计算机类社团学习“现代 Code Agent 是如何写成的”极佳实战教材。
