# Pi：极简轻量级个人伴侣与自主执行核心

Pi 架构主打极简设计哲学、低延迟响应与紧凑的个人记忆沉淀，是智能体领域“反重型框架臃肿化”的代表形态。

---

## 1. 核心档案与指标卡

* **一句话定位**：超低资源占用、高响应度、强调长期个性化记忆的轻量级个人智能体核心。
* **适合谁用**：追求极简代码架构的学习者、希望在低配笔记本或边缘单板机上部署专属助手的极客。
* **门槛指标**：
  * **环境依赖**：极简 Python 环境，无复杂庞大的底层框架依赖链。
  * **操作难度**：★★☆☆☆。

---

## 2. 核心架构与设计哲学

1. **去重型化设计（Minimalist Architecture）**：
   * 剥离了动辄成百上千个抽象类的重型框架包装，保留最核心的“Prompt 编排 + 工具调用分发 + 简易持久化存储”，初学者半小时即可通读其完整源码。
2. **轻量紧凑的个性化长期记忆（Personalized Memory）**：
   * 不盲目堆叠高开销的复杂图数据库，而是采用紧凑的键值与文本分层向量，随会话深入自适应沉淀用户的个人习惯（如喜好的代码风格、常用的项目路径、写作偏好）。
3. **极低资源开销与边缘设备亲和**：
   * 运行时内存占用极小，能够流畅运行在树莓派、轻量云服务器或低配轻薄本上，作为随时待命的后台伴侣。

---

## 3. 适用场景与实践价值

* **随身便携式桌面小助手**：绑定快捷键作为极速搜索与快速备忘录；
* **高校智能硬件与物联网项目**：配合语音唤醒模块部署在嵌入式开发板上，打造具备真正 LLM 逻辑判断能力的实体智能硬件小摆件。
