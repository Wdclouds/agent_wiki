# 03-开源与自主执行框架测评专区

⚠️ **重要提示**：本专区属于**进阶探索版块**，专门面向计算机、软件工程、人工智能等专业，以及有志于参加大创项目、科研课题或对 Agent 底层架构有深度折腾兴趣的同学。

如果你是零基础、文科或仅仅需要日常办公辅助的新生，建议优先使用前两个专区推荐的开箱即用工具，跳过本章亦完全不影响日常学业。

## 1. 为什么有同学会选择“折腾开源框架”？

相比于商业闭源软件，开源与自主执行框架具有三个无可比拟的核心优势：

1. **绝对的数据隐私与合规**：
   * 某些科研课题组的实验数据、涉密代码或病历信息，严禁上传到公网第三方商业云端。开源框架可以 100% 部署在本地私有服务器或本地笔记本上运行。
2. **无限的能力扩展性（二次开发）**：
   * 商业软件只提供固定几个功能按钮；而开源框架允许你用 Python 或 TypeScript 自己写插件、添加自定义工具（如连接学院教务系统、控制实验室机械臂、抓取特定内部论坛）。
3. **深入底层技术内核（科研与大创利器）**：
   * 通过研读开源 Agent 的源代码，你能彻底搞懂 System Prompt 如何注入、上下文如何自动压缩、Subagent 如何异步通信、ReAct 循环如何容错，这些都是极佳的本科毕业设计与大创立项题材。

## 2. 本板块入驻框架速查矩阵

| 框架名称 | 核心侧重 | 适合人群 | 技术特点 |
| :--- | :--- | :--- | :--- |
| **Hermes** | 多任务流转与协同工作空间 | 跨平台部署、任务自动化团队 | 多 Agent 角色隔离、Subagent 并行派发、多端网关联动 |
| **DSH** | 终端深度沉浸交互与排错 | 长期泡在 Linux/WSL 的极客 | 命令行报错自动截获与修复、自然语言转复杂 Shell 管道 |
| **OpenClaw** | 网页数据抓取与深度执行闭环 | 数据挖掘、舆情监控、自动化爬虫 | 强执行力抓取、多工具链调度、自适应反爬重试机制 |
| **OpenCode** | 开源透明的代码编程特工 | 追求纯净无后门、配合本地模型 | 100% 本地日志与 Diff 审查、完美兼容 Ollama 本地模型 |
| **Pi** | 极简微型伴侣架构 | 边缘设备部署、轻量二次开发 | 极低内存开销、紧凑长期记忆、轻量化快速反馈 |
